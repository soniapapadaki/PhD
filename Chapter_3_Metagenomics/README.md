# Chapter 3: The metabolic diversity of endolithic and soil crust microbial communities

Code for Chapter 3 of my doctoral thesis: "Traces of Microbial Life and Activity in Arctic Endolithic Habitats".

## Contents

| File/Directory | Description |
|:---:|:---:|
| microeco_pseq_16S.R | R script for 16S microbiome analysis in Figure 3.1. |
| microeco_pseq_18S.R | R script for 18S microbiome analysis in Figure 3.2. |
| scycdb_barplots.R | R script for SCycDB average gene abundances bar plots in Figure 3.5. |
| `functional profiling` | Initial functional profiling scripts (not used in final analysis). |
